# Meeting notes that never leave your PC / Notas de reuniones que no salen de tu compu

## Why now
Yogurt went public on GitHub on 2026-11-10 and hit Hacker News on 2026-11-11 (241 points). It's a free, MIT-licensed desktop app from Frigade that records a call without a bot, transcribes it with a local Whisper model and summarizes it with a local open-weight model. It has shipped three releases in two days (v0.3.7 on 2026-11-12). Viewers who sit in video calls can install it today on Mac, Windows or Linux.

## Notes for the Producer
- **User decision before capturing:** installing means running an unsigned Windows installer and downloading 5 GB or more of models. If the user says no, build the video from the site and README captures and label the pipeline block as a schematic.
- Version 0.3 and two days old: every feature must be confirmed live before it's shown. Drop any that doesn't work on Windows (HN commenters reported missed speaker names on Teams).
- Record only a self-made test call. Never capture a real meeting with other people.
- "Alternative to Granola" is the authors' own framing (Show HN title). Don't use Granola's logo or UI and don't compare quality.
- Don't say "backed by Y Combinator" about the app: the site says it, but an HN commenter pointed out that applies to Frigade, the company.
- Recording laws differ by country; the script only repeats the project's own advice to tell participants.
- Not claimed: transcription quality, speed, or which model your machine will get (chosen automatically).
- Pronunciation: "Frigade" isn't in the VO on purpose.
