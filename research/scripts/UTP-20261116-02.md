# Your handwriting, as a font / Tu letra, hecha fuente

## Why now
Ductus went public on 2026-11-15 (first archived capture that evening, 368 points on Hacker News the same day). It's a free web page that turns letters you draw with a mouse, trackpad or pen into a real font file you can install. Anyone can try it in two minutes, it looks great on screen, and it lets us explain what a font file actually is.

## Notes for the Producer
- **Date wording:** the page itself has no launch date. "Went up on November 15th" rests on the first Wayback capture and the HN post (both 2026-11-15 19:42 UTC). If the author has posted a launch date by production day, use that.
- **"Saved on your computer"** is what the page says ("Saved on this computer"; the font opener says "checked on this computer, never uploaded"). We didn't audit the network traffic; the VO attributes it ("it says"). Optional: open DevTools → Network while drawing to show no upload, and only then drop "it says".
- **Free / no account:** no price, sign-up or paywall appeared while testing (one letter → export enabled). The page doesn't state a price or a license; don't call it open source.
- Export works after **one** letter ("Write one letter and your font is ready to download. It grows with every letter you add."). The OTF was 2 KB with one test letter. Downloading wasn't tested in research: test the OTF install on Windows before recording.
- A HN user hit an error where the preview stopped and export greyed out. If it happens on camera, reload; don't show it as a feature.
- The "every e looks the same" limit is a fair description of one-shape-per-character fonts; don't say Ductus can never add variants.
- Pronoun: the sources don't state Soren Blank's pronouns. The VO uses the name only; keep it that way.
- Pronunciation: "Ductus" = "DUK-tus".
- The glyph picker and export panel may change fast (new site). Re-check the sets (especially accents) on production day: if accents get added, rewrite the limit row.
