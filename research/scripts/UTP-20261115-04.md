# Outlook is under attack: one file, your login hash / Outlook bajo ataque: un archivo y tu hash de login

## Why now
On 2026-11-10 Microsoft fixed CVE-2026-124194 in Outlook and marked it "Exploited: Yes". CISA added it to its Known Exploited Vulnerabilities catalog the same day (federal deadline 2026-11-24). Opening a crafted message file makes Outlook connect to an attacker's server without the usual external-content warning, which leaks the user's NTLMv2 hash. Classic Outlook is on millions of Windows PCs, and the fix is a manual "Update Now" away. It passed the gate in this morning's run and was held only for variety; nothing in other beats beat it in this run.

## Notes for the Producer
- **Don't say ".msg"**: Microsoft says "a specially crafted message file" and, in another FAQ, "a malicious Office file". Keep "message file".
- **Don't claim** who was attacked, how many, or by whom: Microsoft hasn't said. The acknowledgment credits "Benoit Sevens using Claude with Anthropic" and "nono". That's a possible aside for a later AI-angle video, but it's out of this script (one idea per video), and nothing on the page says what role Claude played.
- **Affected list**: the MSRC entry names Microsoft 365 Apps for Enterprise, Office LTSC 2021 and Office LTSC 2024. The release-notes page also lists Office 2024/2021 Retail and Office 2019 Volume Licensed builds for the same date, but MSRC doesn't list Office 2019 for this CVE, so 2019 is not in the voice-over. The new Outlook for Windows and Outlook on the web are not on the list; don't say they're "safe", only that they're not listed.
- **Build numbers** change: on production day re-open the release-notes page and show the then-current fixed build for the Current Channel (2610 / 20527.20196 on 2026-11-10). The ES voice-over avoids reading the long build number aloud; it's on screen.
- **Spanish UI labels** ("Cuenta de Office", "Opciones de actualización", "Actualizar ahora", "Canal actual") are the usual Spanish Office strings but weren't opened in a Spanish UI this run; match them to what the capture shows.
- If Update Options is missing and only "About" shows, the install is managed (volume license / Group Policy): say "your IT team handles it" instead of showing Update Now.
- The NTLM animation is a schematic and must be labeled. Keep it to "challenge → response proves you know the password" (Microsoft Learn wording). BleepingComputer says the hash can be cracked offline; Microsoft says it "could be used to authenticate as the user". The voice-over uses Microsoft's version.
- Capturing Outlook shows the user's mailbox and account: blur the email address and any message list, or capture only the Office Account pane.
- Overlap: UTP-20261112-01 (Chrome) and UTP-20261115-01 (eMudhra) are also "update now" security videos. Don't schedule them back to back. This makes security 6 of 16 in the queue.
