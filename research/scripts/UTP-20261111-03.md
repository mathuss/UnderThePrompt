# A free SketchUp-style app in your browser / Un SketchUp gratis en el navegador

## Why now
KetchUp, an open-source 3D modeler in the style of SketchUp, hit 769 points on Hacker News on 2026-11-08, the same day its author renamed it BenchUp (release v0.6.6). It has shipped three more releases since (latest v0.6.8 on 2026-11-11). It's free (MIT), runs in a desktop browser with no account, and its repo description says it's "100% vibe-coded". Good for a hands-on video: viewers can open it right now.

## Notes for the Producer
- "100% vibe-coded" is the author's own words in the repo description. Attribute it ("its author says"). In ES, "la hizo 100% con IA" paraphrases "vibe-coded"; keep the attribution.
- Don't say "SketchUp killer" or "replaces SketchUp": the README pitches it for woodworking and furniture. It is not affiliated with SketchUp/Trimble; don't use SketchUp's logo.
- Don't give a reason for the rename: the release note only says "KetchUp is now BenchUp".
- Re-check the version and the browser URL on production day: it ships almost daily (0.6.3 → 0.6.8 in five days). If the UI moved, follow the live app.
- Capture the joints and cut-list steps live: the feature names come from the README; confirm each one works in the browser build before recording, and drop any that don't.
- "Saves in that browser only" = "autosaves locally in the browser". Mention .bup project export via File → Save if it fits.
- Pronunciation: "BenchUp" as "bench-up".
