# The $12.99-a-month embroidery machine, and the free app that replaced it / La máquina de bordar de 12,99 por mes y la app gratis que la reemplaza

## Why now
ZigZag's first downloadable release came out on 2026-11-11 and its author, Kathy Korevec, posted it as a Show HN on 2026-11-12 ("My $300 embroidery machine needed a subscription, so I built my own app"): 740 points and 256 comments, 803 GitHub stars in about two weeks. It's a relatable anti-subscription story with a real how-it-works angle (a reverse-engineered Bluetooth protocol) and a free app anyone with an embroidery machine can try today.

## Notes for the Producer
- Credit (standing rule): say "Kathy Korevec" and show the GitHub repo; credit Jan-Henrik Bruhn / Respira for the Bluetooth protocol on screen and in the description. No photos of either person.
- Pronoun: the sources don't state the author's pronouns. The VO uses the name only; keep it that way in the dialogue version.
- The "$300" in the HN title is the author's figure; no Brother page with the machine's price was opened, so it's **not** in the VO. The $12.99 is Brother's own US price (FAQ); other regions may differ.
- Don't say the machine "needs a subscription to work": the free Artspira tier sends designs and has basic tools (FAQ). Only photo digitizing and some extras are Artspira+. The VO says exactly that.
- Image Trace converts PNG/JPEG logos to shapes (README). Don't call it "photo to stitches" for ZigZag: it's for logos and line art; a photo demo may look poor. Use an SVG or a simple logo.
- Run the Windows build only with the user's OK (unsigned zip; SmartScreen warns, per the README). Re-check the latest release number on production day; the project ships almost daily.
- No machine on hand: the Bluetooth send is a labeled schematic. Don't animate a fake Skitch UI.
- The README says to close Artspira first because the Skitch talks to one app at a time; useful if a viewer asks.
