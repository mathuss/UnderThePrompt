# Your AI agent told websites your email / Tu agente de IA le pasó tu email a sitios web

## Why now
On 2026-11-05 a Claude Code user opened a GitHub issue saying the agent put their email address in the User-Agent header of requests to third-party sites, and that scam emails followed. It was among the top stories on the Hacker News front page (1,166 points on 2026-11-06). On 2026-11-06 a member of the Claude Code team explained the cause on HN: the account email was in the model's context, and Claude sometimes used it as a "contact" in commands it wrote. Version 2.1.317 added a check that asks first; Anthropic says the next release removes the email from the context. Great "under the hood" story about how agents actually make web requests, with a concrete action: update.

## Sources

Still open, 62 comments. Checked 2026-11-06.
- [Hacker News thread](https://news.ycombinator.com/item?id=50385272): 1,166 points. Reply by lydia_hallie (2026-11-06 04:24 UTC), "I work on Claude Code": email added to the model's context for signed-in users (to stop hallucinated names in @author tags); when Claude wrote a command like curl it sometimes put the email in the User-Agent as a contact; removal from context in the next release, "early next week"; 2.1.317+ has a built-in check, on by default, that asks before a web tool call or curl-style command containing the email; "it still doesn't prevent all cases, like when Claude writes a script and runs on its own". Checked 2026-11-06 via the HN Algolia API.
- [Claude Code CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md): 2.1.317 entry quoted above. Checked 2026-11-06.

- [Claude Code setup docs](https://code.claude.com/docs/en/setup): `claude --version`, `claude update`; native installs auto-update; stable channel is about a week behind. Checked 2026-11-06.
- [Wikimedia User-Agent policy](https://foundation.wikimedia.org/wiki/Policy:User-Agent_policy): bots should supply a way of contacting the operator; "an email address, a website, or a wiki user". Checked 2026-11-06.
