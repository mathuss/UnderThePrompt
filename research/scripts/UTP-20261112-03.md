# The skill that updates your AI's web code / La skill que actualiza el código web de tu IA

## Why now
On 2026-11-10 the GoogleChrome/modern-web-guidance repo shipped v1.0.0 and reached Hacker News as a Show HN (429 points). It's a free, Apache-2.0 set of agent skills, stewarded by the Chrome, Edge, Firefox and MDN teams, that steers coding agents from legacy patterns to current web platform features. It installs with one command and can be tried without installing. Audience caveat: this one is for people who build websites with a coding agent.

## Notes for the Producer
- "Like it's 2019" comes from the project's own Show HN title ("off ~2019 JavaScript"); show that title on screen so the hook is attributed.
- "Agents tend to reach for legacy patterns" paraphrases the README's stated goal. Don't add a cause (training data) as fact: the README doesn't state one.
- The popover example comes from the README's guide descriptions (Popover API, native dialogs). For a before/after, capture it live and show exactly what the agent produced; don't stage the "before".
- Eval numbers are a dated snapshot on the README (2026-11-02 to 2026-11-08) and change daily. Re-read them on production day and keep "the project's own tests".
- Telemetry: say it in the VO (it's the honest limit). The on-screen capture should show the `DISABLE_TELEMETRY=1` line.
- Other install routes exist in the README (Claude Code plugin, Codex, Copilot CLI, `npx skills add`, `gh skill install`); not in the VO. Cursor and Gemini CLI were not seen in the README text read on 2026-11-12: don't name them.
- Overlap: UTP-20261105-06 (mattpocock/skills) is also an agent-skill video. Different product and angle; don't schedule them back to back.
