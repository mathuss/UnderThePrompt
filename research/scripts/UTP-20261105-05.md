# Your phone's patch date, decoded / Qué significa la fecha de seguridad de tu celu

## Why now
Google published the November 2026 Android Security Bulletin on 2026-11-02. Its most severe issue, CVE-2026-58868, is rated critical and could allow remote code execution with no user interaction. The bulletin doesn't report it as exploited. The useful, "under the hood" angle: what the "Android security update" date in Settings means, and why there are two November dates (-01 and -05).

- Don't name the affected component: sources disagree (Framework vs Android runtime). The bulletin is the authority; re-check on production day.
- Don't claim exploitation. Re-check the bulletin before rendering; if Google adds an "exploited" note, update the hook.
- Don't claim which phones get it first or how many never get it: not verified on a primary source.
- Buzz is moderate (security press, not top of Reddit): this script passes on `useful`.
