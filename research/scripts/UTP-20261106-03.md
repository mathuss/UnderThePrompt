# Your self-hosted photos app was phoning Microsoft / Tu app de fotos "privada" le hablaba a Microsoft

## Why now
Immich (≈118k GitHub stars) is the best-known self-hosted alternative to Google Photos. Its v3.3.6 release on 2026-11-04 says the team missed that ONNX Runtime, the engine that runs its face recognition and smart-search models, turned telemetry on by default, so the machine-learning container was sending anonymous metrics to Microsoft. It's fixed now. It was a top post on r/selfhosted (RSS, 2026-11-05). The "under the hood" lesson: a dependency deep inside an app can change its privacy behavior without the app's authors noticing.

## Sources
- [Immich v3.3.6 release](https://github.com/immich-app/immich/releases/tag/v3.3.6): published 2026-11-04; "we missed that onnxruntime enabled telemetry by default in a recent release, resulting in the ML container automatically sending anonymous metric data to Microsoft. We have now disabled it." Checked 2026-11-06.
- [Immich PR #32956](https://github.com/immich-app/immich/pull/32956): merged 2026-11-04; "Since 1.29.0, onnxruntime's Linux builds send telemetry to Microsoft (mobile.events.data.microsoft.com) by default… every install sends a persistent device ID along with OS, CPU, RAM and execution provider details"; sets `ORT_DISABLE_TELEMETRY=1`; opt back in with `0`. Checked 2026-11-06.
- [Immich issue #30729](https://github.com/immich-app/immich/issues/30729): opened 2026-08-12, warned about the ONNX Runtime 1.29 default; closed 2026-11-04. Checked 2026-11-06.
- [ONNX Runtime 1.29.0 release](https://github.com/microsoft/onnxruntime/releases/tag/v1.29.0): published 2026-08-12; "POSIX telemetry is now available on Linux, macOS, Android, and iOS… setting ORT_DISABLE_TELEMETRY=1 before initialization disables non-Windows telemetry". Checked 2026-11-06.
- [ONNX Runtime Privacy.md](https://github.com/microsoft/onnxruntime/blob/main/docs/Privacy.md): "Telemetry is turned ON by default in the official builds"; disabling options; persistent device identifier. Checked 2026-11-06.
- [Immich repo](https://github.com/immich-app/immich): "High performance self-hosted photo and video management solution", 118,375 stars; ML README lists CLIP embeddings and facial recognition. Checked 2026-11-06.

## Notes for the Producer
- Say "a self-hosted alternative to Google Photos", not "the Google Photos clone": the repo describes itself as a self-hosted photo and video management solution.
- "Your OS, CPU and RAM" and "persistent device ID" come from Immich's PR description, attributed in the VO ("according to Immich's fix"). Don't add other fields.
- Don't claim which Immich versions were affected or since when: the release note only says "a recent release". Don't claim photos or faces were or weren't sent: no source says either way. The PR lists device ID, OS, CPU, RAM and execution provider; Privacy.md says custom model metadata isn't uploaded. Stick to that list.
- ONNX Runtime is Microsoft's (repo `microsoft/onnxruntime`). Keep "official builds"; private builds can be compiled without telemetry.
- Interest is mostly self-hosters and devs (interest 3); the hook carries it for a general audience. Buzz evidence: r/selfhosted top of week via RSS (2026-11-05 run). No HN thread found.
- Pronunciation: "ONNX" as "onyx"; "Immich" as "IM-ich".
